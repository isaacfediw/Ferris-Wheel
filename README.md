# Ferris-Wheel
This is a personal project I made alone which a model Ferris wheel driven by a belt and stepper motor  

## Hardware
The hardware consists of an arduino nano, and a stepper motor driver  

## Software
To design the Ferris wheel, I used Fusion 360  
To program the arduino I used Arduino IDE    

## 3D Design
To make my design easily printable the main wheel is divided into two sections that can be inserted together with a friction fit. An axle goes through the two segments, also inserted with a friction fit. The axle is supported by two legs, which are screwed into a wooden base. The stepper motor is secured in a 3D printed case, which is screwed into the wooden base
